# Девушка на луне

**Играть онлайн:** [daniilak.github.io/girl-on-the-moon](https://daniilak.github.io/girl-on-the-moon/)

Короткая мобильная HTML5-бродилка (вид сверху) **по мотивам чувашской народной сказки**.  
Ночь, изба, коромысло, прорубь, ведьмы и ясный месяц.

Автор: [daniilak](https://github.com/daniilak) · канал с проектами: [t.me/daniilak](https://t.me/daniilak)

Ключевые слова для поиска: чувашская сказка, девушка на луне, HTML5 игра, мобильная бродилка, пиксель, Чебоксары, чувашские узоры, PWA, indie game.

---

## О сюжете (кратко, своими словами)

Это **не дословная публикация чужого текста**, а короткая **игровая адаптация** народного мотива: падчерицу ночью посылают к проруби за водой; у реки её подстерегают ведьмы; спасение — у лунного камня и месяца.

В README и в игре — собственные реплики и сжатый пересказ. Народные сюжеты как таковые обычно относят к фольклору; спорны бывают **конкретные литературные пересказы** из книг/сборников. Поэтому здесь нет копипаста чужой редакции сказки — только мотив и авторская обработка.

Ход игры: изба → двор и тропа → прорубь → погоня → лунный камень → вознесение → месяц.

## Запуск локально

```bash
cd girl-on-the-moon
python3 -m http.server 8080
```

Откройте `http://localhost:8080` (на телефоне — `http://<IP>:8080`).  
Можно поставить на домашний экран (PWA).

---

## Управление

**Телефон:** крест — ходьба (в настройках — свайп) · Действие · Рывок (в погоне)  
**ПК:** WASD / стрелки · E / Enter · Пробел · Esc

В погоне можно укрыться у стога или плетня. У лунного камня удерживайте Действие; рывок доступен и во время молитвы.

---

## Технологии

Чистый HTML5 / Canvas 2D / Web Audio, без движка и сборки.  
Процедурные спрайты, диалоги, сейвы в `localStorage`, PWA (`manifest` + service worker).  
Чувашские орнаменты из [chuvash-patterns](https://github.com/daniilak/chuvash-patterns) (CC0 1.0).
