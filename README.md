# Девушка на луне — HTML5

Мобильная бродилка под вертикальный экран по мотивам чувашской народной сказки.

## Запуск

```bash
cd "/Users/daniilak/Documents/Игра/girl-on-the-moon-html5"
python3 -m http.server 8080
```

Откройте `http://localhost:8080` или на телефоне `http://<IP>:8080`.  
Можно установить на домашний экран (PWA).

## Управление

**Телефон**
- Крест слева — ходьба (в настройках можно включить свайп)
- **Действие** — осмотреть / говорить / молиться (удержание у камня)
- **Рывок** — ускорение в погоне

**ПК**
- WASD / стрелки — ходьба
- E / Enter — действие
- Пробел — рывок
- Esc — пауза

## Сюжет

Изба → двор и тропа (главная или боковая) → прорубь → погоня ведьм → лунный камень → вознесение → месяц.

В погоне можно укрыться у стога или плетня. У камня удерживайте Действие, пока ведьмы не подошли слишком близко.

## Настройки

Громкость, музыка, эффекты, без звука, вибрация, свайп вместо креста.

## Узоры

В игре используются цифровые чувашские орнаменты из [chuvash-patterns](https://github.com/daniilak/chuvash-patterns) (CC0 1.0): меню, изба, платье, лунный камень, амулет.
